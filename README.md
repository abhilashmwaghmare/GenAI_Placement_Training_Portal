# CloudBlitz GenAI Placement Training Portal

A standalone, responsive learning portal for GenAI placement readiness, trainer-led sessions, interview practice, career profile preparation and an end-to-end GenAI project SOP.

## Features

- CloudBlitz orange and dark professional branding
- **12-day GenAI placement training roadmap**
- Searchable daily syllabus and expected outcomes
- Trainer Mode with day navigation and teaching checklists
- Local browser completion tracking for the 12-day roadmap
- Four-phase Generic GenAI Project SOP: Plan, Build, Validate, Deploy & Handover
- Career Profile Studio for resume, LinkedIn and Naukri readiness
- Responsive desktop and mobile layouts
- Static HTML, CSS and JavaScript; no build tools or server required

## 12-day roadmap

1. Orientation & GenAI Career Roadmap
2. GenAI Resume, LinkedIn & Naukri Profile Building
3. Self-Introduction, STAR Method & Project Storytelling
4. GenAI Roles, Responsibilities & Job Descriptions
5. Documents Preparation & Verification
6. Professional Communication & Interview Confidence
7. GenAI Technical Foundations & Prompt Engineering
8. RAG, Embeddings, Vector Databases & Evaluation
9. Agents, Tool Calling, LangGraph & GenAI System Design
10. Scenario-Based Interview Practice & Job Search Strategy
11. End-to-End GenAI Project: Build, Integrate & Test
12. Project Demo, Deployment Readiness & Final Assessment

## Run locally

Open `index.html` in a browser. All site assets are plain static files.

Live portal: https://abhilashmwaghmare.github.io/GenAI_Placement_Training_Portal/

## Source

The learning design is based on the existing GenAI placement/project SOP content in this repository. Completion marks and trainer checklist states are stored in the current browser using local storage.
