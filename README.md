# CloudBlitz GenAI Placement Training Portal

A standalone, responsive learning portal for GenAI placement readiness, trainer-led sessions, interview preparation, and the four-day generic GenAI project SOP.

## Features

- CloudBlitz orange and dark professional branding
- 15-day placement training roadmap based on the workbook
- Searchable topics and expected outcomes
- Trainer Mode with day navigation and teaching checklists
- Local browser completion tracking
- Four-phase Generic GenAI Project SOP: Plan, Build, Validate, Deploy & Handover
- Placement resource overview for resume, LinkedIn, Naukri, interviews and networking
- Responsive desktop and mobile layouts
- No build tools or server required; static HTML, CSS and JavaScript

## Run locally

Open `index.html` in a browser. All site assets are plain static files.

## Publish using GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then save.
4. After GitHub finishes publishing, the site should be available at:

   `https://abhilashmwaghmare.github.io/GenAI_Placement_Training_Portal/`

## Source

The roadmap and project SOP content are adapted from `GenAI_SOP_for_Placement_and_Project.xlsx`. Completion marks and trainer checklist states are stored in the current browser using local storage.
